software — Snapin 장소 탐색·저장·공유 서비스의 실제 사용 화면
Deal: white-link-blue / Chivo + Chivo Mono / round. 흰색은 사진과 장소 정보를, 블루는 검색·저장·선택 상태를 분명히 드러낸다. Collage hero는 운영 앱에 마케팅용 모형 화면을 넣게 되므로 사용하지 않는다. 기존 앱 셸과 한글 가독성 기준이 우선한다.

## 시각 기준

- Paper #ffffff, Surface #f4f4f4, Ink #111111, Muted #6b6b6b, Action #1a4be0, Line #e4e6eb.
- 한글은 로컬 SUIT Variable, 영문 워드마크는 Chivo를 사용한다. 본문 16px, 메뉴·버튼 14px, 짧은 배지 최소 12px. 기존 공통 크기 토큰을 유지한다.
- 300px 사이드바, 넓은 검색창, 같은 본문 좌우선. 1200px/1000px에서 메뉴 280px/260px, 700px에서 상단 네 탭. 모바일는 내용과 사진을 세로로 배치한다.
- 사진으로 장소를 구분하고, 폴더는 사진 묶음으로 보관한 내용을 예고한다. 모든 영역을 같은 카드로 감싸지 않는다.

```text
메뉴 300 │ 상단 경로 / 넓은 검색 / 배고픈귤
         │ 장소 탐색 제목
         │ 자연어 검색·선택 지역       │ 장소 사진 바로가기
         │ 카테고리 필터 / 검색 결과 수
         │ 장소 사진 │ 장소 사진 │ 장소 사진
         │ 장소 정보 │ 장소 정보 │ 장소 정보
         │ 내 폴더 바로가기
```

## 화면별 목적과 문구

- 장소 탐색: “취향에 맞는 장소 찾기” / “원하는 분위기나 함께 갈 사람을 입력해 보세요.” 검색, 지역 선택, 카테고리, 장소 상세로 이동.
- 통합 링크: “통합 링크 만들기” / 입력과 장소 확인은 왼쪽, 선택한 장소와 지도 선택 구조는 오른쪽. 최근 링크는 단정한 목록.
- 내 리스트: “내 리스트” / 사진을 포함한 폴더 선택, 현재 폴더의 장소·메모·공유. 빈 폴더에서는 통합페이지 저장 흐름을 안내.
- 장소 상세·공유: 장소 사진과 정보, 저장·링크 복사, 지도 선택을 명확하게 구분. 공유 폴더는 함께 담긴 장소를 보여준다.
- 지도 설정: “기본 지도 설정” / 지도 앱 선택 행과 선택 결과 요약. 주요 동작은 설정 적용.
- 지역·저장 대화상자는 네이티브 dialog의 키보드 동작과 취소 의미를 보존.

## 계획 비평과 적용 범위

영문 대문자 장식, 기울어진 사진, 반복되는 연보라 카드와 낮은 대비를 제거한다. 랜딩페이지용 전체 화면 섹션, shader, 스크롤 moment, 마케팅 footer, 거대한 모형 앱은 사용자의 운영 서비스 UI 요구에 맞지 않는다. 짧은 최초 진입과 카드 hover/버튼 press만 사용한다. 기존 사진·별점·주소·시간은 사용자가 요청한 로컬 목 데이터이며 사실 검증이나 새 데이터 수집을 추가하지 않는다. 동일 장소 사진의 반복은 카드·폴더·상세 사이의 시각적 연결이다. 지도는 위치 계산이나 외부 호출 없는 도식이다. ## 2026-11-12 폴더 편집과 장소 큐레이션

운영 서비스 UI / software. 사용자의 기존 보라 테마를 유지한다. 흰색 #ffffff, 바탕 #f8f9fb, 본문 #111111, 보조 #636975, 액션 #8061b0, 선택 배경 #f0eaf8. SUIT 본문 16px·컨트롤 14px·제목 22–32px를 재사용한다.

폴더 목록은 사진과 방문 메모를 읽는 공간으로 두고 항목 우측 점 세 개 메뉴로 편집·삭제를 모은다. 편집 모달에서 메모와 눈/눈꺼짐 공개 상태를 선택한 후 저장해야 반영된다. 폴더 표지는 사진 선택 격자와 업로드 미리보기로 결정한다. 공유 기록은 사진, 날짜, 장소명, 오른쪽 꺾쇠의 한 행으로 전체 클릭을 드러낸다. 검색은 구체적인 성수 노트북 질문과 여러 장소의 별점·대표 의견을 보여주는 큐레이션으로 개선한다.

검토: 랜딩 페이지의 장식·전체 화면 섹션은 실제 앱 작업 흐름에 맞지 않아 추가하지 않는다. 장식 배지 대신 실제 선택 상태와 공개 상태를 표시한다. 사용자 지시에 따라 보라색과 장소 주소·카드 정보는 유지한다. 리뷰의 실제 출처를 확인할 수 없으면 시연 의견으로 분명히 구분한다.
