# 서비스형 프로필·커뮤니티·통합검색 검증

## 최종 변경

- 사용자 화면의 시연·예시 문구와 외부 블로그 리뷰 연결을 제거. 원본 가상 커뮤니티 글 24개를 내부 게시글 경로로 연결. 외부 작성자의 글을 내부 작성글로 재귀속하지 않음.
- 장소별 서로 다른 별점을 글의 별점 평균으로 계산. 카드·상세의 평점과 대표 공감 글이 같은 데이터를 사용.
- 프로필은 조회부터 시작. 닉네임·이메일·사진·소셜 링크와 작성 글/둘러본 장소 수. 수정에서 닉네임·사진·소셜 링크 편집, 저장·취소 분리. 업로드는 브라우저에서만 읽음.
- 사이드바 마이페이지 제거. 상단 검색창은 데스크톱 본문 작업영역 중앙에 배치.
- 장소/지역/태그 및 게시글 제목/본문/작성자 통합검색, 결과 유형별 탭과 개수. 공개 메모만 게시글·검색으로 연결.

## 검증

- npm run lint 통과. npm run build (TypeScript + Vite) 통과. git diff --check 통과. README 0바이트 유지.
- 실제 Chrome 상호작용 통과: 1440px 검색창 중앙 좌표, 서비스 안내 문구 제거, 프로필 최초 조회(닉네임 입력 없음), 사진 파일 선택·미리보기·취소·저장, 닉네임·소셜 링크 반영, 장소+게시글/본문 통합검색, 내부 게시글·연결 장소 이동·공감 버튼.
- 비공개→공개→비공개 전환 시 메모 검색 제외→노출→게시글 접근 차단 통과.
- 390px 프로필 조회·편집, 게시글에서 가로 넘침 없음. 실제 390px/1440px 캡처를 열어 확인. 마지막에는 프로필의 중복 마이페이지 바로가기만 제거했으며 lint/build를 다시 통과.
- 데이터 검사 통과: 24개 내부 글, 장소별 평균 일치와 평점 다양성, 최고 공감 대표 글 ID/수 일치, 본문 검색, URL 한글 검색문·게시글 경로, 성수 노트북 세 곳 유지.

## 범위

API·백엔드·실제 로그인·영구 저장 없음. 이메일·사용자·게시글·별점·공감 수는 운영 화면을 재현하기 위한 로컬 가상 데이터이며 문서에서 관리. 새로고침하면 사용자 변경 초기화. 실제 장소와 사진 출처는 docs/PLACE_SOURCES.md 유지. 프로필 링크는 http/https만 허용. 지도 열기는 사용자가 누를 때 해당 지도 검색 페이지를 새 탭으로 여는 링크이며 지도 API를 연결하지 않음.

이번 증분 작업에서 디자인 스킬 게이트 전체 재검사는 실행하지 않았으며 이전 작업의 GATE: OPEN 48을 최신 기능 검증 결과로 취급하지 않음. 커밋·푸시·배포는 수행하지 않음.

## 후기 본문·공감 버튼 증분 검증

- 공개 방문기의 공간·메뉴·좌석 관찰을 참고하여 8곳 × 3개, 총 24개 글을 새로 작성. 모든 글 3문단 이상·본문 350자 이상, 제목 중복 없음. 출처와 창작 범위는 docs/REVIEW_NOTES_SEONGSU.md 및 docs/REVIEW_NOTES_NEIGHBORHOODS.md.
- 공감 버튼을 본문 하단 중앙에 높이 44px로 배치하고 태그와 구분선·간격으로 분리. 카드 미리보기 본문은 3줄로 제한.
- npm run lint, npm run build, git diff --check 통과. README 0바이트 유지.
- 실제 Chrome 1440/390px에서 공감 버튼 높이·너비·중앙 배치·태그 간격, 공감/취소 시 숫자·aria-pressed, 가로 넘침 없음 검증 통과. 390px 캡처 직접 확인.
- 과거 방문기를 참고했으며 현재 운영 정책을 보장하지 않음. 게시글 작성자·상황·별점·공감 수는 가상 데이터. 커밋·푸시·배포 수행하지 않음.

## 큐레이션 본문 사진 증분 검증

- 기본 24개 게시글 첫째·둘째 문단 뒤에 장소별 사진 2장과 관찰형 캡션 배치. 공개 메모에는 사진을 자동으로 추가하지 않음.
- 8개 장소 추가 사진을 실제 장소와 육안 대조하고 로컬 JPEG로 저장·최대 1200px로 축소. 출처는 docs/POST_PHOTO_SOURCES.md.
- npm run lint, npm run build, git diff --check 통과.
- Chrome에서 24개 글 모두 사진 2장 로딩·대체 텍스트·캡션 확인. 1440/1024/768/390px에서 P/FIGURE/P/FIGURE/P 순서, 이미지 너비, 가로 넘침 없음 검증 통과. 390px 캡처 직접 확인.
