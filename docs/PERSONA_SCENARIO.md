# 스내핀(Snapin) MVP 시연용 페르소나 시나리오

- 작성: 김도언 (11/06 회의 후속 과제: 시연용 페르소나·시나리오). 2026-11-14 목 데이터 추가에 맞춰 갱신.
- 상태: 페르소나의 이름·나이·직업·대사는 시연을 위해 만든 **가상 설정**이다. 인터뷰 결과가 아니다.
- 장소는 **서울의 실제 장소**를 쓴다. 이름·주소·소개·사진 출처는 [PLACE_SOURCES.md](PLACE_SOURCES.md)에 있다.
- 이 문서의 단계와 기대 결과는 2026-11-14에 브라우저 자동 테스트(데스크톱·Android·iOS·카카오톡 환경 에뮬레이션)로 확인했다. **실제 휴대폰에서 지도 앱이 열리는지는 아직 확인하지 않았다.**

## 0. 전제

### MVP 범위 (11/06 회의 기준)

- 반응형 웹앱, 백엔드 없음, 목 데이터. 새로고침하면 사용자가 바꾼 내용(폴더·메모 등)은 초기화된다.
- 시연하는 기능: 통합 링크 만들기, 받는 사람의 기본 지도 앱으로 자동 연결(미설정이면 선택 화면), 자연어 장소 검색(목 데이터 응답), 즐겨찾기 폴더 저장과 폴더 공유 링크, 매장 위치 링크.
- 시연하지 않는 기능: 영상·SNS 속 장소 자동 분석, 랭킹·개인화 추천 고도화, B2B 기능.

### 목 데이터 원칙

- 이름·주소·카카오 장소 ID는 카카오맵 검색 결과와 대조했고, 장소 소개와 사진은 한국관광공사 안내를 따른다.
- 주차·룸·단체석은 **한국관광공사 소개에 적힌 경우에만** 장소 소개에 쓴다. 영업시간은 확인한 곳(앤트러사이트 연희점 등)만 표시하고 나머지는 "방문 전 공식 안내 확인"으로 둔다.
- 장소 코멘트(메모)는 사용자가 쓴 개인 메모 예시이며 시설 검증 자료가 아니다.
- 가상 후기·별점·공감 수가 있는 기존 8곳과 달리, 새로 추가한 7곳에는 가상 후기를 만들지 않았다. 후기가 없는 장소는 "평점 미제공"으로 표시된다.

폴더는 앱 메모리에만 있다. 그래서 **새 탭·폰에서 열려면 처음부터 있는 폴더**를 써야 한다. 새로 만든 폴더의 링크는 같은 탭 주소창에서만 열린다.

### 수신자 링크

- 장소: `#/go/<장소 id>` (예: `#/go/paper`, `#/go/onuel`). 리스트: `#/go/list-<폴더 id>`.
- 링크 만들기에서 만든 링크를 복사하면 위 형식으로 복사된다. 링크 입력창 아래의 예시 버튼으로 네이버·카카오·구글의 검색 링크를 넣어 볼 수 있다.

### 시연 준비와 초기화

1. `npm run dev`로 실행하고 브라우저로 연다. 폰에서 보려면 `npm run dev -- --host`의 Network 주소를 쓰고, **노트북 브라우저도 같은 주소**로 연다(localhost에서 복사한 링크는 폰에서 열리지 않는다).
2. 친구(수신자) 역할 전환: `#/settings`에서 기본 지도를 바꾸거나 **기본 지도 해제**를 누른다.
3. 자동 연결을 다시 보려면 링크를 **새 탭**에서 연다(같은 탭에서 이미 한 번 열린 링크는 자동으로 다시 열지 않는다).
4. PC에서 지도를 고르면 실제 네이버·카카오·구글 웹사이트로 이동한다. 뒤로 가기로 돌아온다.

## 페르소나 1. 지민 (22세, 대학생): 통합 링크 만들기와 자동 연결

| 항목 | 내용 (가상) |
| --- | --- |
| 상황 | 팀플 모임 장소를 성수동 **대림창고**로 정해 단체 채팅방에 공유한다. |
| 문제 | 팀원마다 쓰는 지도 앱이 달라서 한 앱의 링크를 보내면 다른 앱 사용자는 장소를 다시 검색한다. |
| 목표 | 링크 하나로 모두가 자기 지도 앱에서 같은 장소를 연다. |
| 사용 기능 | 통합 링크 만들기, 기본 지도 앱 자동 연결 |

### 행동 흐름

1. 왼쪽 메뉴 **통합 링크 만들기**(`#/link`)로 이동한다.
2. 입력창 아래 예시 버튼 **네이버지도 · 대림창고**를 눌러 네이버 검색 링크를 채운다(실제로는 지도 앱에서 복사한 링크를 붙여넣는 단계).
3. **통합 링크 만들기**를 누른다. 결과 카드에 대림창고의 사진·이름·주소와 링크 `…#/go/paper`가 나온다.
4. **링크 복사**를 누른다. 토스트 "통합 링크를 복사했어요."가 뜬다.
5. 친구 A(기본 지도 네이버): `#/settings`에서 네이버지도를 기본으로 설정한 뒤 복사한 링크를 **새 탭**에서 연다. "네이버지도에서 여는 중이에요"와 진행 막대가 보이고 약 1.6초 뒤 네이버 지도로 이동한다.
6. 친구 B(기본 지도 구글맵): 설정을 구글맵으로 바꾸고 같은 링크를 새 탭에서 연다. 구글맵으로 이동한다.
7. 친구 C(미설정): **기본 지도 해제** 후 같은 링크를 새 탭에서 연다. "어떤 지도로 열까요?" 선택 화면이 뜨고, **카카오맵**을 누르면 대림창고의 카카오맵 장소 상세로 이동한다. "이 지도를 기본으로 사용"을 켜 두었다면 다음부터는 자동 연결된다.

### 기대 결과와 시연 포인트

- 지민은 장소를 한 번만 공유하고, 친구들은 다시 검색하지 않는다.
- **같은 링크가 사용자마다 다른 지도로 열리는 장면**이 핵심 차별점이다.
- 수신자 화면에는 앱 메뉴가 없고 로그인이 필요 없다.

## 페르소나 2. 수현 (28세, 직장인): 강남역 회식 장소 찾기, 저장, 리스트 공유

| 항목 | 내용 (가상) |
| --- | --- |
| 상황 | 팀 회식 장소를 정해야 한다. 조건이 여러 개다(강남역 도보 15분 이내, 주차, 단체석). |
| 문제 | 검색엔진과 SNS에서 후보를 모으고 지도 앱에서 다시 찾느라 시간이 걸린다. 후보를 메모장에 따로 정리한다. |
| 목표 | 조건을 문장으로 입력해 후보를 찾고, 후보 리스트를 팀원에게 한 번에 공유한다. |
| 사용 기능 | 자연어 장소 검색, 폴더 저장, 폴더 공유(통합 링크) |

### 행동 흐름

1. 왼쪽 메뉴 **장소 둘러보기**(`#/explore`)에서 제안 칩 **"강남역 도보 15분 이내, 주차 가능한 단체 회식 장소"**를 누르고 **확인**을 누른다.
2. 약 1초의 "찾고 있어요" 뒤 후보 **5곳**(조양관, 해담채, 강남목장, 동달식당, 강남진해장)과 **추천 기준** 박스가 나온다. 적용한 조건은 "강남역 · 회식 · 단체 · 주차 안내 후보"이고, "소개 기준이라 방문 전 매장에 다시 확인해 주세요" 안내가 함께 나온다.
3. 카테고리 칩 **주차 가능**을 누르면 한국관광공사 소개에 자체 주차장이 적힌 2곳(조양관, 강남진해장)만 남는다.
4. 후보 카드(예: 동달식당 강남본점)를 눌러 통합페이지에서 **내 리스트에 저장** → **새 폴더 만들기**에서 폴더명(예: "회식 후보 2차")을 입력하고 **저장하기**. 토스트 "1개의 폴더에 저장했어요."가 뜬다.
5. **나의 메모 → 편집**(또는 내 리스트의 더보기 → 편집)에서 장소마다 한 줄 코멘트를 남긴다.
6. **내 리스트**에서 폴더를 고르고 **폴더 공유 → 링크 복사**를 누른다. 새로 만든 폴더의 링크는 **같은 탭 주소창**에 붙여넣어야 열린다.
7. 팀원: 미리 만든 **`#/go/list-team-dinner`**를 새 탭이나 폰에서 연다. 후보 3곳과 **공개 코멘트 3개**가 보이고, 지도(예: 카카오맵)를 고른 뒤 장소의 **카카오맵에서 열기**를 누르면 해당 장소의 카카오맵 상세(조양관은 `place.map.kakao.com/8086138`)로 이동한다.

### 기대 결과와 시연 포인트

- 수현은 후보 검색, 정리, 공유를 한 곳에서 끝낸다. 팀원은 후보 목록과 코멘트를 보고 바로 자기 지도 앱으로 이동한다.
- **자연어 조건 입력 → 후보 → 리스트 → 공유 링크**로 이어지는 흐름과, 리스트 안의 각 장소가 팀원 각자의 지도 앱으로 열리는 장면.

### 행동 흐름

1. 민재의 리스트 **성수 맛집 투어**(미리 만들어 둠)에는 대림창고 → 어니언 성수 → 성수족발 → 제스티살룬 성수 → 블루보틀 성수 카페 순서의 5곳과 장소별 한 줄 코멘트가 있다. 직접 만들려면 **장소 둘러보기**에서 "성수 맛집"을 검색해 성수족발·제스티살룬을 담고 카페는 "성수 카페"에서 담는다.
2. 코멘트의 공개 여부는 장소 메모의 눈 아이콘으로 정한다(미리 만든 폴더는 공개 상태).
3. **내 리스트 → 성수 맛집 투어 → 폴더 공유 → 링크 복사**로 링크를 만든다.
4. 팔로워(기본 지도 카카오맵): 설정에서 카카오맵을 기본으로 하고 **`#/go/list-seongsu-tour`**를 새 탭에서 연다. 5곳과 코멘트가 보인다.
5. 장소의 **카카오맵에서 열기**를 누르면 해당 장소의 카카오맵 상세로 이동한다(대림창고는 `place.map.kakao.com/1128989913`).
6. 팔로워가 마음에 드는 장소를 자기 즐겨찾기에 저장하려면 수신자 화면의 장소 페이지(앱 안의 통합페이지)로 들어가서 저장한다.

### 기대 결과와 시연 포인트

- 민재는 링크 하나로 팔로워 전체에게 장소를 전달한다. 팔로워는 검색 없이 자기 지도 앱으로 이동한다.
- **팔로워가 보는 리스트 화면과 장소별 코멘트.**

## 페르소나 4. 하나 사장님 (40대, 동네 카페 운영): 매장 오시는 길 링크

| 항목 | 내용 (가상) |

| 목표 | 링크 하나만 안내하면 고객이 쓰는 지도 앱으로 연결된다. |
| 사용 기능 | 통합 링크 만들기, 수신자 화면 |

시연용 매장 위치는 **앤트러사이트 연희점**(서울 서대문구 연희로 135, 매일 08:50 – 22:00)을 쓴다. 실제 운영자와는 무관한 **시연용 위치**이며 사장님이 이 업체의 운영자라는 뜻이 아니다.

4. 처음 온 고객은 지도 앱 선택 화면을 보고 하나를 누르면 매장 위치가 열린다.

## 알려진 한계와 확인할 것

- **실제 폰 확인 필요**: 네이버·카카오 앱 호출(`intent://`, 앱 스킴), 구글맵 앱 열림, 카카오톡 안에서 링크를 눌렀을 때의 동작. 카카오 앱 스킴(`kakaomap://place?id=`)은 공식 문서를 확인하지 못했다. 실패하면 웹 주소로 이동한다.
- **장소 ID 대조**: 15곳 × 3개 지도의 ID가 해당 장소를 가리키는지 2026-11-14에 PC 브라우저로 상세 페이지를 열어 페이지 제목과 장소명을 대조했다(카카오는 검색 결과의 주소·전화로 대조). 장소를 새로 추가하면 같은 방식으로 ID를 넣어야 한다. 네이버·구글은 공식 API로 ID를 받을 수 없어 지도 앱에서 장소 상세 주소를 복사해 만든다.
- **사진 이용 허락**: 새 7곳의 사진은 한국관광공사 안내 페이지의 대표 사진이며 일부 사진에는 원작자(블로거) 표기가 이미지에 들어 있다. 공개 배포 전에 이용 허락을 확인해야 한다([PLACE_SOURCES.md](PLACE_SOURCES.md)).
- **미구현 화면**: 크리에이터 프로필·클릭 통계, 매장 전용 페이지, 리스트 단위 공개 범위, 수신자 리스트에서 바로 저장.
- **폴더는 메모리에만 존재**: 새로 만든 폴더의 링크는 새 탭에서 열리지 않는다. 시연용 링크는 미리 만든 폴더를 쓴다.

## 인터뷰로 확인할 가설

- 대학생·직장인은 약속 장소를 단체 채팅방 링크로 공유한다.
- 지도 앱이 달라 장소를 다시 검색한 경험이 있다.
- 크리에이터는 설명란에 장소를 텍스트로 적고 있다.
- 매장은 특정 지도 앱 링크만 안내하고 있다.

각 가설은 5~8명 인터뷰에서 해당 경험의 유무와 빈도를 확인한 뒤, 맞으면 유지하고 아니면 시나리오를 고친다.
