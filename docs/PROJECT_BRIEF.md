# 프로젝트 설명

## 1. 의도

- 해결하려는 문제와 이 서비스를 만드는 이유
- 주요 사용자와 사용 상황
- 사용자가 얻어야 하는 가치
- 이번 웹페이지에서 보여주려는 경험과 작업 범위

## 2. 컨셉

- 서비스를 한 문장으로 표현한 핵심 컨셉
- 서비스의 분위기와 주요 키워드
- 사용자에게 전달하고 싶은 인상
- 화면과 문구에 컨셉을 반영하는 방향

## 3. 기본 기능

- 핵심 기능의 이름과 목적
- 각 기능을 사용하는 상황
- 사용자의 입력·행동과 화면에 표시할 결과
- 기능 사이의 연결과 주요 사용자 흐름
- 목 데이터로 보여줄 내용과 동작 범위

### 내 리스트와 통합페이지

- **내 리스트**는 사용자가 이름을 정한 폴더들의 목록입니다. 폴더 안에 장소를 저장합니다.
- **저장한 장소**는 장소명, 사진, 주소, 통합 링크가 연결된 통합페이지를 가리킵니다. 같은 장소를 여러 폴더에 담을 수 있습니다.
- 폴더에서 장소의 통합페이지를 열거나 통합 링크를 복사할 수 있습니다.
- 저장 흐름은 **장소 탐색 → 통합페이지 → 내 리스트에 저장 → 폴더 선택 → 저장**입니다. 탐색 전에 저장 폴더를 지정하지 않습니다.
- 통합페이지의 저장 버튼을 누를 때만 폴더 선택창을 엽니다. 여러 폴더에 저장하거나 새 폴더를 만들어 저장할 수 있습니다. 취소하면 기존 저장 상태를 유지합니다.
- 이미 저장한 장소는 저장된 폴더를 표시하고, 저장 버튼으로 폴더를 변경합니다. 탐색 카드에서는 저장 상태만 표시합니다.
- 공개 큐레이션은 다른 사람이 탐색하는 추천 묶음이고, 내 폴더는 사용자가 보관·정리하는 공간입니다.
- 화면에는 실제 서비스의 작업명과 자연스러운 폴더명·메모를 사용합니다. 목 데이터·초기화 등 개발 설명은 문서에서 관리합니다.
- 데이터와 동작은 로컬 목 데이터 기준이며, 새로고침하면 초기화됩니다. API나 영구 저장은 구현하지 않습니다.

### 공통 탐색 구조

- **장소 둘러보기**: 새로운 장소를 탐색하는 독립 메뉴입니다. 현재는 상위 그룹명 ‘둘러보기’를 별도로 표시하지 않습니다. 공개 큐레이션 등 탐색 메뉴가 늘어나면 그룹화를 검토합니다.
- **내 워크스페이스**: 내 리스트, 통합 링크 만들기, 공유받은 장소, 기본 지도 설정을 다룹니다.
- 장소 둘러보기 하단의 **내가 모아둔 장소**는 내 리스트 바로가기입니다. 공개 큐레이션과 구분해서 표시합니다.
- 상단 경로는 현재 화면이 속한 영역을 표시합니다. 독립 메뉴인 장소 둘러보기는 화면 이름만 표시합니다.

### 검색 지역

- 지역은 필수 입력이 아닙니다. AI 검색창 아래에서 필요한 경우에만 지역을 지정합니다.
- 검색 문장에 적은 지역이 별도로 선택한 지역보다 우선합니다. 적용한 지역을 검색 결과에 표시합니다.
- 지역 선택창은 지역명·역명 검색, 최근 검색한 지역, 전체 지역 선택으로 구성합니다.
- 현재 목업에서는 준비한 지역·역명과 장소를 로컬에서 연결합니다. GPS·와이파이 위치 수집, 브라우저 위치 권한 요청, 실제 AI·장소 검색 API는 연결하지 않습니다.

## 4. 스타일링

- 전체적인 디자인 방향과 참고 화면
- 주요 색상, 배경색, 글자색
- 글꼴, 글자 크기, 제목과 본문의 구분
- 레이아웃, 여백, 정렬 기준
- 버튼, 입력창, 카드, 아이콘의 표현
- 사진과 이미지의 사용 방향
- 선택·호버·포커스 등의 상태 표현
- 모바일과 데스크톱의 배치 기준

### 왼쪽 메뉴 너비

- `src/styles.css`의 `--sidebar-width`를 메뉴 너비와 본문 시작 위치에 함께 사용합니다.
- 기본 300px, 화면 너비 1200px 이하 280px, 1000px 이하 260px를 사용합니다.
- 700px 이하에서는 왼쪽 메뉴를 상단의 네 개 탭으로 전환합니다.

### 공통 글자 크기 기준

아래 기준은 현재 화면에 적용한 규칙입니다. 모든 페이지에서 `src/styles.css`의 CSS 변수를 사용합니다. px 수치는 브라우저 기본 글자 크기 16px 기준입니다.

| 용도 | CSS 변수 | 크기 |
| --- | --- | --- |
| 짧은 캡션·배지·태그 | `--font-size-caption` | 0.75rem / 12px |
| 메뉴·버튼·보조 설명·장소 메타 정보 | `--font-size-small` | 0.875rem / 14px |
| 본문·입력창·컬렉션 이름 | `--font-size-body` | 1rem / 16px |
| 장소 카드 제목·소제목 | `--font-size-card-title` | 1.125rem / 18px |
| 섹션 제목 | `--font-size-section-title` | 1.375rem / 22px |
| 검색 영역 제목 | `--font-size-hero-title` | 1.5rem / 24px |
| 모바일 페이지 제목·상세 제목 | `--font-size-page-title-mobile` | 1.75rem / 28px |
| 데스크톱 페이지 제목 | `--font-size-page-title` | 2rem / 32px |
| 로고 | `--font-size-brand` | 2rem / 32px |

- 글자 크기는 임의의 px 값 대신 위 변수에서 용도에 맞게 선택합니다.
- 일반 본문은 16px, 메뉴와 보조 설명은 14px를 사용합니다. 12px는 짧은 캡션에만 사용하며, 일반 텍스트를 그보다 작게 만들지 않습니다.
- 모바일에서도 본문·메뉴·버튼·입력창 크기는 유지합니다. 공간이 부족하면 줄바꿈이나 열 수·여백을 조정합니다.
- 기본 줄 높이는 1.6, 제목은 1.4입니다. 카드 설명은 두 줄까지 표시합니다.
- 기본 글자 크기를 `100%`로 두어 브라우저의 사용자 글자 크기 설정을 따릅니다.
- 지도 SVG 내부의 지명은 확대·축소되는 그림 요소이며 본문 글자 크기 규칙과 구분합니다.
