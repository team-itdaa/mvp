# 프로젝트 설명

## 1. 의도

- 해결하려는 문제와 이 서비스를 만드는 이유
- 주요 사용자와 사용 상황
- 사용자가 얻어야 하는 가치
- 이번 웹페이지에서 보여주려는 경험과 작업 범위

## 2. 컨셉

- 서비스를 한 문장으로 표현한 핵심 컨셉
- 서비스의 분위기와 주요 키워드
- 사용자에게 전달하고 싶은 인상
- 화면과 문구에 컨셉을 반영하는 방향

## 3. 기본 기능

- 핵심 기능의 이름과 목적
- 각 기능을 사용하는 상황
- 사용자의 입력·행동과 화면에 표시할 결과
- 기능 사이의 연결과 주요 사용자 흐름
- 목 데이터로 보여줄 내용과 동작 범위

### 내 리스트와 통합페이지

- **내 리스트**는 사용자가 이름을 정한 폴더들의 목록입니다. 폴더 안에 장소를 저장합니다.
- **저장한 장소**는 장소명, 사진, 주소, 통합 링크가 연결된 통합페이지를 가리킵니다. 같은 장소를 여러 폴더에 담을 수 있습니다.
- 폴더에서 장소의 통합페이지를 열거나 통합 링크를 복사할 수 있습니다.
- 저장 흐름은 **장소 탐색 → 통합페이지 → 내 리스트에 저장 → 폴더 선택 → 저장**입니다. 탐색 전에 저장 폴더를 지정하지 않습니다.
- 통합페이지의 저장 버튼을 누를 때만 폴더 선택창을 엽니다. 여러 폴더에 저장하거나 새 폴더를 만들어 저장할 수 있습니다. 취소하면 기존 저장 상태를 유지합니다.
- 이미 저장한 장소는 저장된 폴더를 표시하고, 저장 버튼으로 폴더를 변경합니다. 탐색 카드에서는 저장 상태만 표시합니다.
- 공개 큐레이션은 다른 사람이 탐색하는 추천 묶음이고, 내 폴더는 사용자가 보관·정리하는 공간입니다.
- 화면에는 실제 서비스의 작업명과 자연스러운 폴더명·메모를 사용합니다. 목 데이터·초기화 등 개발 설명은 문서에서 관리합니다.
- 데이터와 동작은 로컬 목 데이터 기준이며, 새로고침하면 초기화됩니다. API나 영구 저장은 구현하지 않습니다.

### 공통 탐색 구조

- **장소 둘러보기**: 새로운 장소를 탐색하는 독립 메뉴입니다. 현재는 상위 그룹명 ‘둘러보기’를 별도로 표시하지 않습니다. 공개 큐레이션 등 탐색 메뉴가 늘어나면 그룹화를 검토합니다.
- **내 워크스페이스**: 내 리스트, 통합 링크 만들기, 공유받은 장소, 기본 지도 설정을 다룹니다.
- 장소 둘러보기 하단의 **내가 모아둔 장소**는 내 리스트 바로가기입니다. 공개 큐레이션과 구분해서 표시합니다.
- 상단 경로는 현재 화면이 속한 영역을 표시합니다. 독립 메뉴인 장소 둘러보기는 화면 이름만 표시합니다.

### 검색 지역

- 지역은 필수 입력이 아닙니다. AI 검색창 아래에서 필요한 경우에만 지역을 지정합니다.
- 검색 문장에 적은 지역이 별도로 선택한 지역보다 우선합니다. 적용한 지역을 검색 결과에 표시합니다.
- 지역 선택창은 지역명·역명 검색, 최근 검색한 지역, 전체 지역 선택으로 구성합니다.
- 현재 목업에서는 준비한 지역·역명과 장소를 로컬에서 연결합니다. GPS·와이파이 위치 수집, 브라우저 위치 권한 요청, 실제 AI·장소 검색 API는 연결하지 않습니다.

## 4. 스타일링

- 전체적인 디자인 방향과 참고 화면
- 주요 색상, 배경색, 글자색
- 글꼴, 글자 크기, 제목과 본문의 구분
- 레이아웃, 여백, 정렬 기준
- 버튼, 입력창, 카드, 아이콘의 표현
- 사진과 이미지의 사용 방향
- 선택·호버·포커스 등의 상태 표현
- 모바일과 데스크톱의 배치 기준

### 왼쪽 메뉴 너비

- `src/styles.css`의 `--sidebar-width`를 메뉴 너비와 본문 시작 위치에 함께 사용합니다.
- 기본 300px, 화면 너비 1200px 이하 280px, 1000px 이하 260px를 사용합니다.
- 700px 이하에서는 왼쪽 메뉴를 상단의 네 개 탭으로 전환합니다.

### 공통 시각 기준

- 흰색 `#ffffff`, 본문 바탕 `#f8f9fb`, 진한 글자 `#111111`, 보조 글자 `#636975`, 주요 동작 `#75559f`, 브랜드 `#8061b0` (파스텔 보라 계열), 구분선 `#e4e6eb`를 사용합니다. 배경·글자·선택 상태는 `src/styles.css`의 색상 변수를 재사용합니다.
- 한글 UI는 로컬 SUIT Variable, 영문 로고는 로컬 Chivo를 사용합니다. 글꼴은 외부 서비스 호출 없이 제공합니다.
- 본문 좌우 여백은 데스크톱 40px, 작은 데스크톱·태블릿 28px, 모바일 20px입니다. 제목·입력·목록의 시작선을 맞춥니다.
- 장소 탐색은 검색과 사진, 내 리스트는 폴더의 사진 미리보기와 메모, 통합페이지는 장소 정보·지도 선택·저장, 링크 만들기는 입력·결과를 우선합니다. 서비스 사용 화면에 마케팅용 전체 화면 섹션이나 장식용 대시보드를 추가하지 않습니다.
- 패널 20px, 장소 카드·폴더 16px, 입력·버튼 10px의 모서리를 사용합니다. 긴 설명 전체를 같은 카드 형태로 감싸지 않습니다.
- 검색·선택·포커스에 보라를 사용하고, 장소 사진은 충분한 크기로 보여줍니다. 카드의 저장 배지는 상태 표시이며 직접 저장 버튼이 아닙니다.
- 사진 확대·카드 이동·버튼 누름은 `public/assets/motion/`의 공통 동작을 사용합니다. 스크롤에 맞춰 내용을 감추거나 자동 재생하지 않습니다. 동작 줄이기 설정을 따릅니다.
- 모바일에서는 장소 카드와 폴더를 한 열로 배치하고, 링크 만들기·설정·통합페이지는 내용을 세로로 쌓습니다. 긴 글자의 크기를 줄여 맞추지 않습니다.

### 공통 글자 크기 기준

아래 기준은 현재 화면에 적용한 규칙입니다. 모든 페이지에서 `src/styles.css`의 CSS 변수를 사용합니다. px 수치는 브라우저 기본 글자 크기 16px 기준입니다.

| 용도 | CSS 변수 | 크기 |
| --- | --- | --- |
| 짧은 캡션·배지·태그 | `--font-size-caption` | 0.75rem / 12px |
| 메뉴·버튼·보조 설명·장소 메타 정보 | `--font-size-small` | 0.875rem / 14px |
| 본문·입력창·컬렉션 이름 | `--font-size-body` | 1rem / 16px |
| 장소 카드 제목·소제목 | `--font-size-card-title` | 1.125rem / 18px |
| 섹션 제목 | `--font-size-section-title` | 1.375rem / 22px |
| 검색 영역 제목 | `--font-size-hero-title` | 1.5rem / 24px |
| 모바일 페이지 제목·상세 제목 | `--font-size-page-title-mobile` | 1.75rem / 28px |
| 데스크톱 페이지 제목 | `--font-size-page-title` | 2rem / 32px |
| 로고 | `--font-size-brand` | 2rem / 32px |
| 넓은 화면의 탐색 제목 | `--font-size-discovery-title` | 2.625rem / 42px |

- 글자 크기는 임의의 px 값 대신 위 변수에서 용도에 맞게 선택합니다.
- 일반 본문은 16px, 메뉴와 보조 설명은 14px를 사용합니다. 12px는 짧은 캡션에만 사용하며, 일반 텍스트를 그보다 작게 만들지 않습니다.
- 모바일에서도 본문·메뉴·버튼·입력창 크기는 유지합니다. 공간이 부족하면 줄바꿈이나 열 수·여백을 조정합니다.
- 기본 줄 높이는 1.6, 제목은 1.4입니다. 카드 설명은 두 줄까지 표시합니다.
- 기본 글자 크기를 `100%`로 두어 브라우저의 사용자 글자 크기 설정을 따릅니다.
- 지도 SVG 내부의 지명은 확대·축소되는 그림 요소이며 본문 글자 크기 규칙과 구분합니다.

### 장소·메모·탐색 UX

- 장소와 대표 사진은 `docs/PLACE_SOURCES.md`의 실제 장소 자료를 사용합니다. 장소별 평점은 준비한 커뮤니티 글의 별점 평균을 사용합니다. 데이터의 출처와 목업 범위는 문서에서 관리하며 서비스 화면에는 개발용 안내를 노출하지 않습니다.
- 개인 메모는 기본 비공개입니다. 리스트와 통합페이지에서 공개 여부를 바꾸며 공개한 메모만 커뮤니티에 표시합니다.
- 공유받은 장소 메뉴는 열어본 통합 링크의 장소 히스토리이며 장소를 선택하면 통합페이지로 이동합니다.
- 검색 입력은 즉시 결과를 바꾸지 않습니다. 확인 후 약 1초 대기한 다음 지역·태그 기준 요약과 결과를 표시합니다. 실제 AI 추론이나 API 호출은 없습니다.
- 닉네임 클릭으로 프로필 설정을 열고 마이페이지와 기본 지도 설정에 접근합니다.

### 폴더 편집·썸네일·큐레이션

- 폴더 항목의 점 세 개 메뉴에서 편집과 폴더에서 삭제를 제공합니다. 메모는 읽기 상태로 표시하고, 편집창에서 메모와 공개 범위를 선택합니다. 눈 아이콘은 공개, 눈에 사선 아이콘은 나만 보기입니다. 저장 전에는 변경하지 않고 취소·Escape는 기존 상태를 유지합니다. 기본은 나만 보기입니다.
- 새 폴더를 만들 때 기본 이미지, 준비한 장소 사진, 사용자가 선택한 로컬 사진을 대표 이미지로 사용할 수 있습니다. 업로드는 브라우저에서만 읽고 서버로 전송하지 않습니다. 폴더 저장창에서 새 폴더를 만드는 경우에도 같은 선택을 제공합니다.
- 공유받은 장소 기록은 열어본 날짜·시각을 함께 표시하고, 전체 행과 오른쪽 꺾쇠로 상세 이동을 나타냅니다. 다시 공유 링크를 열면 최근 날짜·순서를 갱신합니다. 초기 기록은 시연 데이터입니다.
- 성수 노트북·콘센트·넓은 좌석 질문은 성수 카페 세 곳의 시연 후보 목록을 반환합니다. 시설 검증이나 실제 AI 추천이 아니며 미확인 안내를 표시합니다. 검색 결과와 통합페이지의 별점·대표 의견·공감 수는 같은 시연 데이터를 사용합니다. 대표 의견은 예시 의견 중 공감 수가 가장 큰 항목입니다. 실제 리뷰를 수집한 것처럼 표시하지 않습니다.

- 성수 세 카페에는 실제 공개 방문기의 작성자·작성일·원문 링크와 요약을 별도로 표시합니다. 확인되지 않은 실제 별점·공감 수는 만들지 않습니다. 기존 커뮤니티 공감 순위는 명시된 시연 의견에만 적용합니다.

### 운영형 화면·프로필·통합검색 (최신 기준)

- 사용자 화면의 시연·예시 안내를 제거합니다. 여전히 API·백엔드·실제 로그인·영구 저장 없이 로컬 상태를 사용하는 목업입니다.
- 커뮤니티는 외부 방문기 링크 대신 자체 작성한 가상 게시글 24개의 내부 상세 화면을 제공합니다. 외부 작성자의 글을 서비스 내 작성글로 재귀속하지 않습니다. 장소별 세 게시글의 별점과 평균, 작성자, 공감 수를 다르게 구성합니다.
- 상단 중앙 통합검색은 장소명·지역·태그와 게시글 제목·본문·작성자를 검색합니다. 장소와 게시글 결과를 나눠 보여주고 각각 상세로 이동합니다. 공개한 개인 메모는 내부 게시글·검색에 포함하며 비공개 메모는 제외합니다.
- 프로필은 닉네임 클릭 시 조회 화면부터 표시합니다. 닉네임·이메일·프로필 사진·SNS 링크·작성한 글 수·둘러본 장소 수와 수정·설정 동작을 제공합니다. 둘러본 장소 수는 서비스에서 연 장소 페이지 수이며 실제 물리적 방문 인증이 아닙니다.
- 프로필 수정에서 닉네임, 로컬 사진, http/https 소셜 링크를 변경합니다. 저장해야 반영하며 취소·Escape는 변경을 버립니다. 이메일은 조회만 합니다. 사이드바의 마이페이지 진입은 제거합니다.
- 위 기준이 과거의 시연 라벨·외부 리뷰 출처 링크 UI 기준보다 우선합니다. 사진 출처 자료는 계속 문서에서 관리합니다.
